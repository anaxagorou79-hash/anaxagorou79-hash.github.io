PERSONAL-USE GOOGLE INTEGRATION

Hermes Datamind

A private, owner-operated connection between a local Hermes assistant and the owner's Google Drive and Calendar.

This website documents the integration. It does not provide a public sign-in service, accept document uploads, or display account data.

What the integration does

  • Connects to Google using an installed desktop OAuth client.
  • Uses read-only Drive and Calendar permissions. Drive permissions technically cover all files, but operational use is limited to explicitly selected folders and relevant work requested by the owner.
  • Retrieves relevant information only for an authorized task. No Drive content is read while no folders have been selected.
  • Stores OAuth credentials locally using Windows current-user encryption and refreshes them when Google permits.

Owner control

The connection does not authorize automatic email sending, invitations, file sharing, deletion, background ingestion, or spending. Existing Gmail access is a separate integration, not a scope of this desktop client.

Read the privacy policy and terms of use before using the integration. This is not an official Google product or a service operated by Nous Research.
